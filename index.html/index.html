THE IDEA BEHIND THE BOT

About UniBot

A student-focused virtual campus assistant project.

✦

Making campus information easier to find.

UniBot is a simple web-based assistant designed to help students find answers to frequently asked university questions from one place.

🎯

Project objective

Reduce the time students spend searching for routine campus information by organising common questions and answers in one accessible interface.

⚙️

How it works

The website checks the words in a student's question against a small FAQ knowledge base and displays the closest matching answer.

💻

Technology used

HTML structures the pages, CSS creates the design, and JavaScript powers chat interactions, FAQ search and question matching.

Project prototype notice

This demonstration uses sample FAQ information. It is not connected to Bennett University's official portal, LMS, fee system or live student database. Policies, dates and amounts must be verified with official university sources.
